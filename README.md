# Polaris AI: Antarctic Navigation Decision Support System (SIH26059)

Polaris AI is an AI/ML-driven decision-support platform engineered for safe, fuel-efficient maritime navigation in the Weddell Sea, Antarctica.

## Features
- **Multi-Sensor Fusion:** Integrates Sentinel-1 SAR imagery, ERA5 atmospheric reanalysis, and NIC sea-ice records.
- **CROMA Foundation Model:** Utilizes pretrained cross-modal SAR-optical representations for sea-ice feature extraction.
- **Predictive Trajectories:** Forecasts iceberg drift and regional sea-ice concentration shifts.
- **Safe Routing Engine:** Computes optimal low-risk corridors balancing voyage duration, fuel economy, and structural safety.
